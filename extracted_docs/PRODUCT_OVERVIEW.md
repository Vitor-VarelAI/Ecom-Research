# Product Overview

Windsurf é um **painel de controlo para pesquisa de produtos e nichos em e-commerce**, usando dados reais de procura, comportamento de anúncios e análise de sentimentos.

## Objetivo
Permitir decisões baseadas em dados antes de lançar produtos.

## Utilizadores-alvo
- Criadores de marcas DTC
- Fundadores de e-commerce
- Agências de ads e product researchers
